## ⚡ How to Run Locally

Because `ROHIT.OS` is built using pure modern web standards (Vanilla HTML5, CSS3, ES6+ JavaScript, Canvas2D, and Web Audio API), it requires **zero build steps or heavy node modules**!

### Option A: Using Python (Installed on your system)
Open PowerShell or Command Prompt in the `rohit-os` directory:
```powershell
# Navigate to the rohit-os directory
cd C:\Users\ROHIT\.gemini\antigravity-ide\scratch\rohit-os

# Start Python's built-in HTTP server
C:\msys64\ucrt64\bin\python.exe -m http.server 8000
```
Then open your browser at:
`http://localhost:8000`

### Option B: Using VS Code Live Server
1. Open the `rohit-os` folder in VS Code.
2. Click **Go Live** on the bottom right toolbar.

## ✏️ How to Customize Your Information

All content is cleanly decoupled in `js/portfolio-data.js`:
- **Add New Projects**: Add an object to `window.ROHIT_DATA.projects` with `title`, `summary`, `problem`, `solution`, `techStack`, `demoUrl`, and `githubUrl`.
- **Confirm Hackathon / Mission**: When the **JECRC AI Hackathon 2026** is completed, move it from `pendingMissions` to `confirmedMissions` and set `status: "CONFIRMED & COMPLETED"`.
- **Update Skills**: Modify `window.ROHIT_DATA.capabilities` with new stages (`BUILDING`, `MASTERED`).
- **Profile Photo**: Either drag & drop your photo onto the portrait card on the live site, or replace the `src` attribute of `#portrait-photo-element` in `index.html`.

## 🚀 Deployment to GitHub Pages

1. Initialize git in the folder:
   ```bash
   git init
   git add .
   git commit -m "Initialize ROHIT.OS digital universe"
   ```
2. Create a repository on your GitHub account (`https://github.com/RohitXpert/rohit-os`).
3. Push to GitHub:
   ```bash
   git remote add origin https://github.com/RohitXpert/rohit-os.git
   git branch -M main
   git push -u origin main
   ```
4. In GitHub repository settings, go to **Pages** → select `main` branch → Save.
5. Your universe is live!
